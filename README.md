# Netflix Landing Page Clone

A responsive clone of the Netflix landing page built with HTML and CSS, showcasing modern web design techniques and layout practices.

## 🎯 Project Overview

This project recreates the Netflix landing page interface, focusing on responsive design, clean UI/UX, and pixel-perfect styling to match the original Netflix aesthetic.

## 🚀 Features

- **Responsive Design**: Fully responsive layout that adapts to different screen sizes
- **Modern UI**: Clean and attractive interface matching Netflix's design language
- **Pure HTML/CSS**: Built without frameworks, demonstrating core web development skills
- **Asset Management**: Organized assets folder for images and media

## 📁 Project Structure

```
Netflix-Landing-Page/
├── assets/           # Images, icons, and media files
├── netflix.html      # Main HTML file
├── style.css         # Styling and layout
└── .gitignore        # Git ignore configuration
```

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Styling, flexbox/grid layouts, and responsive design

## 💻 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sk8infinity18/Netflix-Landing-Page.git
```

2. Navigate to the project directory:
```bash
cd Netflix-Landing-Page
```

3. Open the HTML file in your browser:
```bash
# On Linux/Mac
open netflix.html

# Or simply double-click the netflix.html file
```
